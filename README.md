# 🍽️  Kim Restaurant  Website

A simple and responsive restaurant website built using **HTML** and **CSS**. This project showcases a restaurant's homepage and menu with an easy-to-navigate layout.

## 📌 Features

- Responsive navigation bar
- Home page
- Restaurant menu page
- Clean and modern design
- Mobile-friendly layout
- Easy to customize

## 📂 Project Structure

```
restaurant-menu/
│
├── index.html          # Home page
├── menu.html           # Menu page
├── style.css           # Stylesheet
├── images/             # Images used in the website
└── README.md           # Project documentation
```

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚀 Getting Started

1. Clone the repository.

```bash
git clone https://github.com/yourusername/restaurant-menu.git
```

2. Navigate to the project folder.

```bash
cd restaurant-menu
```

3. Open `index.html` in your preferred web browser.

No installation or additional software is required.
